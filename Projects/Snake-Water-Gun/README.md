# 🐍 Snake Water Gun Game

My first Python project — a simple Snake Water Gun game.

## 🎮 About

In this game, the player competes against the computer.

- 🐍 Snake beats 💧 Water
- 💧 Water beats 🔫 Gun
- 🔫 Gun beats 🐍 Snake

## 🧠 Concepts Used

- Python functions
- if / elif / else
- User input
- Random module
- Variables
- Basic programming logic
